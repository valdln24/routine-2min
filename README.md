# Routine LR

Quiz « Trouvez votre routine LR idéale en 2 minutes » : 5 questions, une routine matin et soir, puis un contact direct par WhatsApp, appel ou SMS.

- Tout est dans `index.html` : aucune installation, aucun serveur.
- Vos informations (prénom, WhatsApp, photo) : bloc `CONFIG` en bas du fichier.
- Les produits : bloc `P`. Les questions et les points : bloc `QUESTIONS`.

## Mise en ligne (Cloudflare Pages, gratuit)
Cloudflare › Workers et Pages › Créer › Pages › Connecter à Git › `routine-lr`.
Aucune commande de build, dossier de sortie : `/`.
